# Application Objets Perdus & Retrouvés

Application Flutter pour la gestion d'objets perdus et retrouvés.

## Structure du projet

```
lib/
├── main.dart                    # Point d'entrée
├── theme/
│   └── app_theme.dart          # Thème Material 3 avec couleurs violet
└── pages/
    ├── language_selection_page.dart
    ├── home_page.dart
    ├── lost_form_page.dart
    ├── found_form_page.dart
    └── publications_page.dart
```

## Installation

1. Installer les dépendances :
```bash
flutter pub get
```

2. Lancer l'application :
```bash
flutter run
```
